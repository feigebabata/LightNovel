# 轻小说翻译

- 轻小说翻译工作流
- 在汉化资源出现之前先自己尝个鲜

## 思路
- 使用大模型更自然的翻译轻小说
- 由于大模型的上下文限制 所以需要逐章翻译
- 由于大模型的上下文限制 需要建立全局的索引表（主要是人名）

## 实践步骤

### 1.获取生肉资源
- web版 例: https://ncode.syosetu.com/n6100jr/ 提供的pdf文件
- 文库版等
- 或爬取或扫描件 大模型都可以转录出生肉文本

### 2.逐章切割
- 按章节切割为单个txt文件 直接交给大模型就行
- 为保障顺序可以添加需求 例:"每章一个txt文件 文件名格式 “第n章 章节名” 不要出现非法路径字符"

### 3.建立翻译规范文档
- 直接问大模型翻译轻小说要注意什么
- 让它根据自己的回答生成"注意事项文档"
- 让它浏览全文后生产全局术语表(人名/称谓/地名/组织等文档)
- 翻译进度表 记录翻译进度

### 4.逐章翻译
- 开始翻译 交给大模型就行
- 如果翻译几章后就停下让它继续就行
- 翻译后 可以添加简单的章节分割符 然后合并成一个文档就结束了

### 5.更新
- 小说出了新章节 还是先获取生肉资源
- 已有翻译进度表 只处理新内容
- 更新步骤三的文档
