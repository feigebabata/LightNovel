# 《彼女をデレさせる方法を、将来結婚する俺だけが知っている》翻译资料

本目录基于已切分的 135 个日文 TXT 章节做全局粗读，供后续逐章翻译时统一使用。当前目标语言预设为**简体中文**；机器可读术语以 `术语总表.tsv` 为准，人物关系、时间线和文风规则分别见对应文件。

## 文件说明

- `术语总表.tsv`：人物、地名、组织、专有名词、格式标签及统一译法。
- `人物与称呼.md`：主要人物关系、不同人物对他的称呼、说话特征。
- `时间线与视角.md`：时间回溯前后的时间节点、未来篇定位和多视角提醒。
- `翻译规范.md`：文风、敬称、人名、标点、段落和消息格式。
- `章节索引.tsv`：135 个本地章节的类型、视角线索、文件路径和长度。
- `翻译进度.tsv`：逐章翻译时的状态台账，初始状态均为“未翻译”。
- `待确认与原文瑕疵.md`：原文内部不一致、暂译名和需要人工复核的点。
- `glossary.json`：供程序或后续翻译流程读取的结构化术语数据。

## 使用顺序

1. 每章翻译前先检索 `术语总表.tsv` 和 `人物与称呼.md`。
2. 判断该章位于校园主线、未来片段、番外还是闲话，再读取 `时间线与视角.md`。
3. 翻译后按 `翻译规范.md` 检查称呼、第一人称、标点和段落。
4. 遇到 `待确认与原文瑕疵.md` 中记录的问题，按“统一建议”处理，不要自行创造第三种写法。
