# 全局翻译规范

## 总体目标

- 目标语言：简体中文。
- 文体：现代日式轻小说中译，口语自然，保留网文独有的即时感和角色吐槽。
- 基本原则：准确优先；在准确的前提下让中文像中文，而不是逐句复刻日语句法。
- 不擅自增加情节、心理活动、人物关系或网络梗，也不为了“通顺”删掉暧昧、伏笔和语气。

## 人称与文风

- 男性第一人称统一「我」，保持正修的成年判断、冷幽默和自嘲，不用过密网络流行语。
- 女性第一人称也用「我」，由姬的句子可以更克制、更讲究，但也保留她激动时的短句和内心尖叫。
- 正修独白可适当使用「说到底」「讲真」「真是够了」等自然口语，但每段不要连续堆砌。
- 枫的「〜っす」用明快、略假小子的口语体现，不写成粗俗方言。
- 优马用松散、挑衅、带笑意的口吻；静香保持礼貌措辞，同时保留温柔腹黑。
- 理沙要吵、跳脱、夸张，但不要译成低龄幼稚。

## 姓名与敬称

- 日文姓名保持姓在前、名在后，如「有栖川由姬」。
- 不随意把姓改成中文习惯称呼；只有原文出现昵称时才使用昵称。
- `さん`：校内多用「同学」；成人正式语境可用「小姐」「女士」或省略。
- `くん`：校园语境多为「同学」；明确学长关系时用「学长」。
- `ちゃん`：亲近关系用「小＋名」；不要全书机械加「酱」。
- `先輩`：通常译「前辈」，需要明确性别时可用「学长」「学姐」。
- `様`：商务或服务语用「您」「女士」「客人」，不要一律译「大人」。
- 敬称的变化代表关系变化。不能为了句子顺口随意删掉或添加。

## 对话与标点

- 日文外层引号「」译为中文双引号“”。
- 引号内再引用的『』译为中文单引号‘’。
- 电话、短信和引用内容也统一进入中文引号体系，不为保留日式外观而混用「」。
- 长音和破折号 `ーー`、`――` 按语境译成破折号 `——`。
- 省略号统一 `……`；问号、叹号使用中文全角。
- `＊＊＊` 场景分隔符保持原样。
- 对话不额外添加说话标签。原文依赖上下文时，用保留动作句和清晰指代解决。

## 段落格式

- 对话段落以 `“` 开头，不加行首空白。
- 叙述段落沿用原文的 `　` 全角空格作首行缩进。
- 作者宣传、系统标签、标题和场景符号不强行套叙述缩进。
- 不在句子中间机械插入换行；中文长句按语义拆分，不按日文原行宽切断。
- 手机消息、系统通知和引文单独成段，保留原文的层级。

## 专有名词

- 以 `术语总表.tsv` 为准，不在不同章节自行替换译名。
- 企业英文品牌优先保留拉丁名：ALISCOA、Cross Streamers、Ring Reard。
- 首次出现可用「ALISCOA（阿利斯柯亚）」帮助读音，之后可只用 ALISCOA。
- 学校职务：会长、副会长、会计、书记、宣传、总务。
- 「自治会」坚持译「居民自治会」，以免与学生会混淆。

## 特殊标记

| 原文 | 统一形式 |
|---|---|
| 《未来》 | 【未来】 |
| 《おまけ》 | 【番外】 |
| 《閑話》 | 【闲话】 |
| 《宣伝》 | 【宣传】 |
| 《予告》 | 【预告】 |
| 【由姫視点】 | 【由姬视角】 |
| 【注意】 | 【注意】 |

书名和章节名的最终译法可另做总表，但正文中的标签必须统一。

## 内容与语气

- 保留正修的成年人对未成年身体的尴尬、克制和自嘲，不改成纯校园少年口吻。
- 保留由姬的防御性、嘴硬和实际上的关心；不要把她翻成永远尖酸刻薄的人。
- 性暗示和亲密场景按原文尺度翻译，不额外升级，也不自行净化。
- 作者前書き、後書き和宣传语可适度理顺，但不能伪造日期、链接、销量或出版信息。
- 双关无法完全保留时，优先保住当前对话效果；必要注释放句末「（译注：……）」。

## 校对清单

- 本章视角人物是否一致。
- 称呼是否随关系与场景变化，但没有随机漂移。
- 人名、企业名、学校职务是否与术语表一致。
- 是否把「未来」误改成普通闪回，或把婚后姓名当成新人物。
- 是否存在漏句、重复句、否定词遗漏。
- 引号是否成对，消息格式是否清楚。
- 是否出现过度书面化、网络梗堆积或低龄化撒娇。
